# Data Dictionary

## Dataset Overview

The dataset contains hourly air-quality and meteorological observations from monitoring stations in Chennai, Delhi and Mumbai for 2021–2023.

## Variables

| Variable | Description | Unit |
|---|---|---|
| Timestamp | Date and time of observation | Date/Time |
| PM2.5 | Fine particulate matter | µg/m³ |
| PM10 | Particulate matter | µg/m³ |
| NO | Nitric oxide | µg/m³ |
| NO2 | Nitrogen dioxide | µg/m³ |
| NOx | Oxides of nitrogen | ppb |
| NH3 | Ammonia | µg/m³ |
| SO2 | Sulphur dioxide | µg/m³ |
| CO | Carbon monoxide | mg/m³ |
| Ozone | Ground-level ozone concentration | µg/m³ |
| Benzene | Benzene concentration | µg/m³ |
| Toluene | Toluene concentration | µg/m³ |
| Xylene | Xylene concentration | µg/m³ |
| O Xylene | o-Xylene concentration | µg/m³ |
| Eth-Benzene | Ethylbenzene concentration | µg/m³ |
| MP-Xylene | m,p-Xylene concentration | µg/m³ |
| AT | Ambient temperature | °C |
| RH | Relative humidity | % |
| WS | Wind speed | m/s |
| WD | Wind direction | degrees |
| RF | Rainfall | mm |
| TOT-RF | Total rainfall | mm |
| SR | Solar radiation | W/m² |
| BP | Barometric pressure | mmHg |
| VWS | Vertical wind speed | m/s |

## Variables Used in the Project

### Target Variable

**Ozone (µg/m³)** – ground-level ozone concentration.

### Meteorological Variables

- **AT** – Temperature
- **RH** – Relative Humidity
- **SR** – Solar Radiation

These three variables are the main explanatory variables investigated in this project.
