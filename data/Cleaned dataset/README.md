# Cleaned Dataset

This folder contains the cleaned versions of the air-quality datasets used in the Datathon project.

## Cities

- Chennai
- Delhi
- Mumbai

## Cleaning Process

The datasets were processed using Python before being used for analysis.

The cleaning workflow included:

- Combining station-level data
- Standardizing date/time information
- Identifying and handling duplicate records
- Identifying missing values
- Handling missing numerical values
- Checking numerical values for invalid negative measurements
- Preparing the data for statistical analysis and prediction

## Files

- `Chennai.zip` — Cleaned Chennai dataset
- `Delhi.zip` — Cleaned Delhi dataset
- `Mumbai.zip` — Cleaned Mumbai dataset

## Important Note

The cleaned datasets are derived from the original source datasets stored in the `Raw dataset/` folder.

The cleaning process was performed to prepare the data for subsequent Datathon rounds while preserving the important structure and variables of the source data.
