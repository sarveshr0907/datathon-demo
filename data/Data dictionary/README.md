# Data Dictionary

This folder contains documentation describing the variables used in the Datathon air-quality dataset.

The main data dictionary is available at:

`data/data_dictionary.md`

## Dataset Coverage

- Cities: Chennai, Delhi and Mumbai
- Stations: 9
- Time period: 2021–2023
- Frequency: Hourly
- Total observations: 236,520

## Main Variables

| Variable | Description | Unit |
|---|---|---|
| PM2.5 | Fine particulate matter | µg/m³ |
| PM10 | Particulate matter | µg/m³ |
| Ozone | Ground-level ozone concentration | µg/m³ |
| AT | Ambient temperature | °C |
| RH | Relative humidity | % |
| WS | Wind speed | m/s |
| WD | Wind direction | degrees |
| SR | Solar radiation | W/m² |
| RF | Rainfall | mm |
| BP | Barometric pressure | mmHg |

For the complete list of variables and descriptions, refer to `data_dictionary.md`.
