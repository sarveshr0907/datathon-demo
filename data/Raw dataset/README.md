# Raw Dataset

This folder contains the original air-quality datasets used for the Datathon project.

## Cities

- Chennai
- Delhi
- Mumbai

## Dataset Coverage

- Time period: 2021–2023
- Frequency: Hourly
- Monitoring stations: 9
- Source CSV files: 27
- Total observations: 236,520

## Files

- `Chennai.zip` — Raw Chennai station data
- `Delhi.zip` — Raw Delhi station data
- `Mumbai.zip` — Raw Mumbai station data

## Data Source

The raw datasets were obtained from the government air-quality data source used for the Datathon.

These files represent the original source data and are retained separately from the cleaned datasets.

## Important Note

The raw datasets should not be modified directly. Any cleaning or preprocessing should be performed on a copy of the data so that the original source records remain available for reference and verification.
