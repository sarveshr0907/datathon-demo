# AI Usage Disclosure

## Purpose

AI tools were used as supporting tools during the development and documentation of this datathon project.

## Areas Where AI Was Used

AI assistance was used for:

- Understanding and explaining dataset-related concepts.
- Supporting Python code development and troubleshooting.
- Reviewing data-analysis workflows.
- Helping structure project documentation.
- Improving clarity and organization of README files and round-wise documentation.
- Supporting interpretation and presentation of analysis and model results.

## Human Responsibility

The team reviewed, tested and verified the project outputs before including them in the repository.

AI tools were used as assistance and did not replace the team's responsibility for:

- Data preparation
- Analysis
- Model development
- Result verification
- Final interpretation
- Project decisions

## Transparency

All final project files, analysis results and documented findings were reviewed by the team before submission.
