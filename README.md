# 🏛️ College Datathon Demo Repository

Welcome to the official demo repository for our college's inaugural datathon. This repository documents our end-to-end dry run to test the competition workflow, dataset quality, round-wise structure, and judging metrics before opening it up to participants.

## 📂 Repository Structure

- `data/` — Raw dataset, cleaned CSV files, and data dictionary.
- `Round 1 – Data Audit/` — Data quality checks, missing values, distributions, and Answer Key.
- `Round 2 – Statistical Investigation/` — Research question, hypothesis testing, and statistical findings.
- `Round 3 – Prediction/` — Predictive modeling task, code, evaluation metrics, and hidden test scores.
- `Round 4 – Final Solution/` — Practical recommendations, final impact report, and final PPT.
- `AI Usage/` — Documentation of AI tools utilized during development and verification steps.

## 🚀 Team & Workflow
- **Event:** College Datathon 2026
- **Objective:** Validate the 24-hour participant timeline and automated scoring systems.
